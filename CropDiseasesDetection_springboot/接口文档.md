# CropDiseasesDetection SpringBoot 接口文档（v1）

## 1. 基本信息
- 服务地址：`http://localhost:9999`
- 统一前缀：`/api/v1`
- 认证方式：`Authorization: Bearer <accessToken>`

## 2. 统一响应
```json
{
  "code": "SUCCESS",
  "message": "ok",
  "data": {},
  "traceId": "a1b2c3d4",
  "timestamp": "2026-05-09T20:00:00+08:00"
}
```

## 3. FoxAPI/Apifox 测试方法（可直接照做）
1. 启动顺序：
- MySQL
- Flask（`http://127.0.0.1:5000`）
- SpringBoot（`http://localhost:9999`）

2. 在 FoxAPI 建环境变量：
- `baseUrl=http://localhost:9999`
- `username=admin`
- `password=123456`
- `accessToken=`
- `refreshToken=`
- `taskNo=`
- `jobNo=`
- `experimentNo=`

3. 登录拿 token：
- `POST {{baseUrl}}/api/v1/auth/login`
```json
{
  "username": "{{username}}",
  "password": "{{password}}"
}
```
- 把 `data.accessToken`、`data.refreshToken` 保存为环境变量。

4. 所有鉴权接口统一 Header：
```http
Authorization: Bearer {{accessToken}}
Content-Type: application/json
```

5. 推荐联调顺序：
- 登录：`POST /api/v1/auth/login`
- 验证：`GET /api/v1/auth/me`
- 创建图片任务：`POST /api/v1/predictions/image-tasks`
- 查任务：`GET /api/v1/tasks/{taskNo}`
- 创建训练实验：`POST /api/v1/training/experiments`
- 对比实验：`GET /api/v1/training/experiments/compare?leftNo=...&rightNo=...`

6. 常见问题：
- `UNAUTHORIZED`：没带 token 或 token 过期
- `FORBIDDEN`：角色权限不足
- `UPSTREAM_FLASK_ERROR`：Flask 未启动或上游异常

## 8. 训练实验管理接口（新增）

### 8.1 创建实验
- `POST /api/v1/training/experiments`
- 请求示例：
```json
{
  "experimentName": "rice-yolo11n-aug-v3",
  "datasetName": "rice_leaf_2026",
  "paramsJson": "{\"epochs\":120,\"imgsz\":640,\"batch\":16}",
  "resultJson": "{\"bestEpoch\":87}",
  "remark": "加入增强后提升",
  "map50": 0.912,
  "map5095": 0.658,
  "trainLoss": 0.084,
  "valLoss": 0.102
}
```

### 8.2 查询实验详情
- `GET /api/v1/training/experiments/{experimentNo}`

### 8.3 实验分页查询
- `GET /api/v1/training/experiments?pageNum=1&pageSize=10&experimentName=rice&datasetName=2026`

### 8.4 更新实验
- `PATCH /api/v1/training/experiments/{experimentNo}`
- 请求示例：
```json
{
  "remark": "调整学习率后更稳定",
  "map50": 0.918,
  "map5095": 0.664,
  "trainLoss": 0.079,
  "valLoss": 0.097
}
```

### 8.5 删除实验
- `DELETE /api/v1/training/experiments/{experimentNo}`

### 8.6 对比两个实验（mAP/loss 差异）
- `GET /api/v1/training/experiments/compare?leftNo=EXPxxx&rightNo=EXPyyy`
- 返回说明：
  - `left`：左侧实验
  - `right`：右侧实验
  - `diff`：差值（`left - right`）
    - `map50Delta`
    - `map5095Delta`
    - `trainLossDelta`
    - `valLossDelta`
